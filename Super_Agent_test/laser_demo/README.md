# 多段移动与虚拟激光互动演示

`output/demo_final.mp4`：DeepSeek Harness 与官方 Super-agent 仿真适配实例驱动的合成家庭互动。左上为仿真 RGB 相机；左下为根据 ROS 机器人位姿及关节状态同步重建的斜侧方观察视角；右侧是精简事件和对话摘要。末尾的最后一轮模型回应由同一实例续录并拼接，非单一连续实录；时间上省略了续录前的等待。视觉帧按墙钟时间补帧。

本次依次执行四段固定 world 坐标路线：活动点、植物观察点、电视观察点、等待点；均读取仿真位姿做闭环，并在等待点停止。三次点示分别为植物、叶片、电视；云台达到预设角度后开启 4 秒虚拟提示并关闭。`output/skill_*.json` 保存各段和云台动作的反馈。它们是预设路线和预设提示点，不是从语义地图坐标自主计算的导航目标，未验证实机导航或安全性。

虚拟光束和光点只由录制器绘制：根据同步的相机姿态，用 MuJoCo 射线计算与可见几何的交点，在旁观画面画光束、在第一人称图像叠加光点。它不是物理激光器，也不是相机自身拍到的激光；没有验证实机光路、遮挡或人眼安全。机器人模型、成员状态和回应都是仿真或预设；没有真实儿童、真实语言识别、语音播放或屏幕控制。对话中的“预设提示/反馈”不是模型生成，Agent 行为和完整模型回复见 `output/replies.jsonl`。

已有语义地图来源为 `semantic_video_map.json`；地图引用的数据库与 `improved_map.db` 的 SHA-256 一致。地图只作为交互对象语义输入，地图坐标系到仿真世界坐标系未校准。`output/memory.json` 是含合成历史和本轮偏好的演示文件，不是生产长期记忆系统。

注意一次真实模型输出将预设观察点说成“植物旁边”，且在激光关闭后说“正指向”；这些描述未被定位或当前激光状态证实。视频中额外给出定位澄清，原始回复保留在日志中。`output/story_result.json` 的 success 只表示脚本条件和技能反馈成功，不代表上述语义正确性或实际安全性验证。

`output/requests.jsonl`、`replies.jsonl`、`decisions.json`、`timeline.jsonl` 为合成任务及 Agent 记录；`stage_final.json` 是续录时 Worker 对模拟成员新选择的回应。录制脚本、场景脚本、ROS 技能及启动脚本保存在此目录及其父目录，运行环境参见父目录 README。
