# 硬件与计算部署初案

状态：讨论稿；采购和算力选型须依据实测、预算及实际设备接口确定。

## 部署原则

优先采用机器人端 + 家庭本地计算节点；用户数据本地存储，不默认上传云端。家庭局域网内的主机与远程服务器不是同一个边界。家庭外的开发服务器适用于合成或获准使用的开发数据、模型训练及评估，不默认接收真实家庭数据；远程推理即使不持久保存也会传输用户数据，需要单独明确产品边界及授权。

## 原型硬件

- 低速差速底盘：带编码器的电机与驱动、IMU、电源管理、可靠的急停及防碰撞结构；根据房间和机器人尺寸确定尺寸与功率。
- 传感器：RGB-D 相机（如 RealSense D435i，需按近距离和安装位置实测）、2D 激光雷达、近距离防碰撞传感器、碰撞触边及必要的防跌落传感器；需要评估低矮、透明物和盲区，不能假设传感器组合天然安全。
- 交互：麦克风阵列、扬声器、显示屏、摄像头物理遮挡及麦克风物理静音/状态指示；儿童使用环境需评估声压、音频清晰度与可视交互。
- 计算与存储：机器人端开发可先用现有 x86 主机，部署候选为 Jetson Orin NX 16GB；家庭本地主机可按模型实测配置 GPU。使用加密 SSD，容量按数据策略确定。性能、供电、散热、功耗及 ROS/驱动兼容性均需验证。
- 电池及 BMS、电源保护、稳定和防夹手的结构设计；器件和整机需经过实际安全验证。

## 模块位置

| 模块 | 推荐位置 | 说明 |
| --- | --- | --- |
| 急停、底盘底层控制和看门狗 | 机器人端独立控制器 | 不依赖网络、高层模型或主机进程 |
| 定位、局部避障、传感器读取 | 机器人端 | 局域网中断时仍可安全停止；运动能力以实测和安全条件为准 |
| 视觉/语音前处理、小型实时模型 | 优先机器人端 | 对算力不足的任务可在家庭本地主机处理，但不能承担唯一安全保护 |
| 语义地图、交互与任务决策、ASR/TTS、较大模型 | 机器人端或家庭本地主机 | 按延迟、性能和家庭配置实测划分；需明确断网降级 |
| 用户资料、记忆、交互记录和原始数据 | 本地加密存储 | 默认最小化采集与保存；家长可管理、导出和删除 |
| 模型研发、合成数据训练、软件更新 | 开发端/远程服务器 | 不默认上传用户数据；更新包需要完整性校验和回滚 |

## 降级与验证

家庭主机或网络不可用时，安全控制继续有效；依赖本地主机的功能应停止或降级，移动是否允许需通过安全评估决定。优先验证儿童语音识别、音频输出和视觉交互、家庭环境定位避障、数据生命周期以及实际模型并发与延迟。儿童数据采集及任何研究用途应明确监护人授权、用途、保存期限和适用要求。
